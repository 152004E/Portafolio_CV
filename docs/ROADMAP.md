# Visión a Largo Plazo (ROADMAP.md)

## Hitos del Proyecto
- **Milestone 1 (MVP Estático)**: Portafolio funcional One-Pager con Astro, Tailwind v4 y datos gestionados de manera local en un archivo `.ts`.
- **Milestone 2 (Integración Continua)**: Despliegue automático en plataforma Edge (Vercel/Netlify) vinculado al repositorio.
- **Milestone 3 (Internacionalización - i18n)**: Soporte dinámico para rutas `/en` y `/es` con Astro i18n para llegar a reclutadores internacionales.
- **Milestone 4 (Blog / Artículos)**: Habilitar las colecciones de contenido de Astro (`Content Collections`) para incluir artículos técnicos renderizados a partir de archivos Markdown o MDX.
